LaynFleet

LaynFleet is a complete local transport and ride-hailing software ecosystem built by Digilayn. It pairs passenger on-demand requests with independent drivers through real-time dispatch, democratic driver rate governance, live GPS radar, and transparent upfront pricing.

From idea to Google Play

Musa Mgijima independently built LaynRider’s native Android app, serverless backend and supporting web tools, taking ownership from implementation through testing and public release.

The app uses Kotlin and Jetpack Compose. Firebase Authentication, Firestore, Realtime Database, Cloud Storage and Cloud Functions support sign-in, data, live updates and backend workflows, without maintaining application servers.

Musa coordinated community volunteers for closed testing without paid tester services, and took LaynRider through Google Play’s testing and production review process. The app is now publicly available on Google Play.

Huawei AppGallery release preparation is underway. Musa is also learning AWS to build backend applications in future.
